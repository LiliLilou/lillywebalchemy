## Context

BSides Belgrade is a community-driven cybersecurity conference. The site had to sell tickets, recruit speakers through a call for papers, showcase sponsors and publish the agenda.

## My role

Freelance with Jungle Creatives, in a wider role than pure development: I wrote the site copy, contributed ideas to the designer, handled on-page SEO across the whole site, and edited the code where needed.

## The challenge

Speaking to two audiences at once, attendees and potential speakers or sponsors, while keeping the site easy to find in search for a one-day event.

## Why plain files

Built in plain HTML, CSS and JavaScript on purpose. For a cybersecurity conference, no CMS, no database and no build dependencies means the smallest possible attack surface.

## The solution

- Copy written around clear calls to action: get tickets, become a speaker, download the sponsorship brochure
- SEO across every page: titles, meta descriptions, Open Graph images for sharing
- A lean multi-page structure: home, schedule, sponsors, about, code of conduct, call for papers

## Result

A fast, focused conference site that carries the event from call for papers to the day itself.
